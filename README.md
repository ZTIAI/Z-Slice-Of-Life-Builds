# Z Slice Of Life: playtest builds

**Z Slice Of Life** is a visual novel: a Company-approved workplace romance inside the most powerful, most absurd corporation on Earth, which slowly turns into psychological horror.

**Download:** https://ztiai.github.io/Z-Slice-Of-Life-Builds/

**18+.** Content note: this game turns into psychological horror. It contains disturbing images, including blood.

This repository holds **only the built game's update files** and the download page. The game updates itself from here (Windows and Linux).
